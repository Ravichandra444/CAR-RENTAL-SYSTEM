# DriveEasy - Car Rental System

## SDC Project
A frontend-only car rental application developed using HTML, CSS and JavaScript.

### Modules
- User Module: Signup, Login, search cars, booking, booking history.
- Admin Module: Admin login, dashboard, vehicle inventory, add/delete vehicles.

### Technologies
HTML5, CSS3, JavaScript, Local Storage, CSS Grid/Flexbox.
